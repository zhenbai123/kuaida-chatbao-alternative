# 快答-聊天宝替代开源app v1.7.1

用于 Windows 10 / 11（64位）的本地话术悬浮窗。无需激活码或账号，完全离线使用，不需要服务器、数据库或AI服务。源码采用MIT许可证。

## 打开与升级

完整解压到固定的可写目录，双击`QuickReplyLite.exe`。系统需要.NET Framework 4.8。程序启动时尝试在当前用户桌面创建或复用「快答」快捷方式，使用蓝色耳机图标。主窗口右下角「桌面」也可以重建图标；桌面权限错误不影响进入软件。

快捷方式指向解压后的程序，保留整个程序文件夹。其他程序的同名快捷方式保留，必要时会使用编号名称。

从已有版本迁移时，先关闭旧程序，把旧的`Data`文件夹完整复制到开源版程序旁边，话术、素材和设置即可继续使用。无需复制授权文件。授权版和开源版请分开放置，各自使用自己的`Data`；默认程序目录不能写入且没有既有数据时，仍使用`%LOCALAPPDATA%\QuickReplyLite\Data`，请用右下角「数据」核对实际路径。

## 吸附当前窗口

先点击要跟随的聊天窗口，再回到快答，勾选「开机启动」旁的「吸附当前窗口」。
快答会无间距紧贴目标窗口边缘，随它移动、调整位置；目标最小化或隐藏时快答一起收起，恢复时自动出现。
右侧空间不足时自动贴左边；目标铺满屏幕时保持在屏幕内侧，不会调整目标窗口大小。
吸附期间，发送和双击粘贴固定指向绑定窗口。仍需先点击目标聊天输入框。
取消勾选恢复自由拖动；目标关闭后自动解除并显示快答。重新打开软件需要重新选择目标。

## 主要功能

- 点击左侧箭头，粘贴话术并按「回车发送」设置发送；双击话术始终仅放入聊天框。
- 文字、本地图片和文件，每条最多9个附件；编辑窗口支持图片缩略图及放大预览。
- 公共、个人与自定义大板块，分类自动换行，支持搜索、关键词及底色。
- 悬浮置顶、固定位置大小、开机启动、长按拖动排序、正文批量精确替换。
- 导入导出`.quickreply`话术包、CSV文字表格，兼容已验证结构的`.bangkefu`；可选目标大板块，支持追加去重和带备份的替换。

发送会使用系统剪贴板。不同聊天软件的图片及文件确认方式可能不同，首次在自己的测试会话中验证。导入导出结构见`FORMAT.md`、`BANGKEFU-FORMAT.md`。

## 本地数据

数据默认保存在程序旁的`Data`，包括`话术.json`、备份与`素材`。点击右下角「数据」打开实际位置，完整复制该文件夹即可备份。删除话术后素材副本保留，便于恢复。升级程序保留整个Data文件夹。

## 编译

Windows安装.NET Framework 4.8开发环境后，双击本源码包内的`build-windows.cmd`，结果位于`release/`，无需npm或Electron。

完整项目通过`OPEN_SOURCE_EDITION`标志构建免激活版。此专用源码包已移除授权版的条件分支，不包含激活窗口、公钥、授权校验或管理员签发模块；没有激活门禁，也不会读取本地授权文件。随包构建脚本可直接编译，不需要任何密钥。

数据层测试需要.NET 8 SDK：

```sh
dotnet run --project tests/CoreTests.csproj
```

源码与编译后的Windows EXE、应用图标及ZIP完整性均会核对。核心测试在 Windows 上运行，功能页面截图使用演示数据。实际桌面快捷方式、系统自启及各聊天软件发送兼容性请在自己的 Windows 电脑上验证。
